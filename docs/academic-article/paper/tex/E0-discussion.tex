\subsection{Discussion}
\label{sec:discussion}

Most of these negative results are bounds rather than equivalences, which was not evident when they
were first written down: five of the studies run on five fixtures, where the sign-flip floor of
Equation~\eqref{eq:floor} puts $\alpha$=0.05 out of reach whatever the effect size. That also
inverts the cheap fix. On an underpowered paired design the instinct is to add repeats, and on
clustered data a sixth fixture would have halved the attainable p while a sixth repeat on five
fixtures moves it not at all.

The literature we counter-searched against locates silent failures at the boundary between modules,
and four of our seven crossed such a boundary while three crossed none. What the seven share is not
a boundary but an attribution: an ablation varied a deterministic reconciliation step and we
attributed the difference to a language model, a rank correlation ordered a configuration flag and
we attributed it to parameter count, and a renamed output ceiling let us attribute boundedness to a
component that had never been bounded. The number was real each time, and the arrow pointing to its
cause was drawn by us. Seven cases from one project is not a class, so this is a proposal rather
than a taxonomy, but it suggests a different question from the one boundary-oriented thinking asks:
not whether a component failed silently, but whether each number's cause was measured or assigned.
The clustered-inference correction is that question turned on ourselves, answered badly.

None of this shows negotiation to be worthless, model capacity to be off the ceiling, or verbal
confidence to be uninformative. Each holds at this design's resolution, on this corpus. What we can
say is what each mechanism cost.
