# Live Monitor

The Live Monitor allows you to interact with the Triage™ sandbox for behavioral analysis.

## High latency

You may see a banner warning when using the Live Monitor which says:

```
High latency (<int>ms)
Experiencing performance issues? Click here for more information
```

If you see this warning and do not experience any issues using the Live Monitor, you can safely ignore it.

The following issues are caused by high latency between the client and the sandbox:

-
mouse not working

-
delayed mouse movements

-
mouse clicks are not registered

-
sandbox responds slowly to inputs

-
VM thumbnail on left shows different contents to large viewer

Latency between the client and the sandbox can be caused by many factors, including but not limited to: geographic distance from the backend infrastructure, network connectivity issues with your ISP or tethered connection, and Virtual Private Networks (VPNs) or network security applications.

You can run more detailed tests using our [Troubleshooter](https://tria.ge/troubleshooting).

## Shared clipboard

We do not currently support copy/paste in the Live Monitor.
