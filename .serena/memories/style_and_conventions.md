# Style and Conventions
- **Language**: English for all code, comments, variables, and commit messages.
- **Python Version**: 3.13+
- **Type Hints**: Required (mypy strict mode).
- **Line Length**: 100 characters (Ruff rule). E501 is ignored for LLM prompt strings in agent files.
- **Linting & Formatting**: Ruff rules: E, F, I, W, UP, B. isort for absolute imports.
- **Emojis**: NO emojis in code.
- **Async-first**: DB/Redis/HTTP operations use async/await.
- **Dependency Injection**: Use `ServiceContainer`.
- **Validation & ORM**: Pydantic v2 and SQLAlchemy 2.0.
- **Environment**: Two config systems: `src/maljan/core/config.py` (Core, '__' delimited) and `apps/api/app/config.py` (API, flat).
