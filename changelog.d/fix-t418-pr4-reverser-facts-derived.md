### Changed

- **A decompiler's or disassembler's tools are read from what it lists, and Ghidra's and radare2's blocks say what their tools do as a whole (T-418).** The per-tool categories, arguments, read-only marks and effect exceptions of the 165 Ghidra and 33 radare2 tools are gone. For any server whose block's `roles` hold `decompiler` or `disassembler`, each tool its server does not declare is read from its MCP definition when it is listed (`core.program_reading`): its category by its name's first word; its arguments by exact role words (`program`; a code or memory address, never a struct's, a base's, a diff's `address_a` or a hash routine's address; a file path of a tool that does not change the program); `read_only` for a listing, read or code listing that takes no path, only where the block says its tools run nothing and reach no network and, where its `sample_open` names the program arguments, it takes one, so a tool that reads what every job shares (`list_open_programs`, `list_scripts`) always runs again; and what it does beyond answering where its definition says so (an `emulate` verb emulates, a required code, script or command argument runs whatever it is given, a tool that says it uploads the file sends its bytes). Two new server-level declaration fields say what a block's tools do as a whole: `default_effects`, laid under each tool's own effects, and `analyse_effects`, over it for the tool `sample_open.analyse_tool` names, which may now be named with no open tool. The Ghidra and radare2 blocks ship `default_effects` `{executes: no, network: false, third_party: no}`, and radare2's `sample_open: {analyse_tool: analyze}` with `analyse_effects` saying it emulates at analysis level 2 and above; Ghidra's `run_analysis` gains nothing of it. No Ghidra or radare2 tool reads as sending the sample. Ghidra over HTTP now reads its `/mcp/schema` as a listing (its HTTP method is not read: Ghidra opens and saves by `GET` and reads by `POST`), and Ghidra over stdio keeps what it read; both read the same 165 tools alike. What is read is kept with the server's declaration past the process. Against the former tables, the category, effects and `discloses_sample` read the same for all 198 tools, the arguments for 194 (a range's `start_address` is now its address; `open_project` and radare2's `list_files` name a path), `read_only` for 193, and no repeated call of the stored runs is answered otherwise. What is read by a tool's kind (its kind, report sections, answer rows and the tools a batch aggregates) is still shipped for Ghidra and radare2 (`core.builtin_reverser_kinds`), a leftover that a reading by verb and object removes.
