### Fixed

- **The sample's import-table and similarity digests indicate the sample in STIX (T-498).** The IOC table, `/iocs` and MISP publish the imphash, ssdeep and TLSH as the sample's own digests, and the export carried their indicator related to nothing while every other published indicator had an `indicates` edge to the malware object. It now gets the platform's `indicates` edge like every other indicator, named by the report object; its `anomalous-activity` type and its description still say it also matches files that share the sample's imports or most of its bytes. An indicator typed `benign` and one the judge related otherwise are left as before.
- **A published user agent gets a Suricata rule (T-498).** The Suricata draft read the published domains, addresses and URLs only, so a user agent the run publishes from the call that sends it had no rule. Each published user agent now gets an `http.user_agent` content rule, after the other rules so their SIDs do not move, with the value's quotes, semicolons, parentheses and control characters written as hex bytes, the publish reason in the comment above it, and the per-kind cap and its closing note as the other kinds have.
