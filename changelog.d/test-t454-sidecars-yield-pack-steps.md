### Changed

- **A test holds that each shipped sidecar, switched on as compose runs it, gives the pack its step (T-454).** Each of the eight built-in sidecars (Detect It Easy, ILSpy, GoReSym, YARA-X, oletools, webcrack, unblob, JADX) is switched on as shipped, its block is checked against the read-only sample mount the compose file gives its service, and the run's step list is asked for its steps. The pack's rule that stops a server that would be sent the sample over a network reads the declared `sample_mount`, not the transport, so a mounted HTTP server is never stopped by it; an HTTP server with no mount, and one whose tools declare they send the sample out, are still left out. The steps of the servers that read one code runtime (ILSpy, GoReSym) run where an identification server names it, so they are off while that server is not on. No code changed.
