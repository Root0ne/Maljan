### Added

- **Static & code shows the call map: the functions the sample's code calls, as far as the analysis read it (T-485).** Each function the run's code reading touched is listed with the functions it calls, the functions that call it, whether an analyst read its listing or a call only named it, and a link to the evidence record that holds the listing. A tree opens from the functions nothing calls, one function at a time with the pointer or the keyboard (arrow keys, Home, End, Enter, and O to open the records that hold the focused function's listing), keeping one tab stop; a function that calls back up the tree is drawn once with a "calls back to" marker; the first twenty-five roots and fifty callees of a function are drawn before offering the rest. A list beside it is searched by address, offset or name and narrowed to read or not-read functions. A run that read no code says so in the block's place. The map comes from `GET /api/v1/jobs/{job_id}/evidence/call-map`, derived from the job's stored evidence when asked for, from whatever tools' listings and function index answers it holds, so a run stored before this change has one too; no stored report, ledger or replay output changes.
