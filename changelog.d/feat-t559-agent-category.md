### Added

- **Every agent definition declares its category (T-559).** `agents.definitions.<key>.category` says what the agent does, separate from the code its `role` runs: `code_reader` (Reverser), `static`, `dynamic` (sandbox), `network`, `intel` (reputation) or `other`. The platform offers an agent its own steps by it; a category never restricts the tools an agent may call. The first step keyed on it is the unread-functions question (T-558): an agent in `code_reader` is asked it whenever its entries list code, and where none does its conversation says why; an agent in `static`, `dynamic`, `network` or `intel` is not asked; for `other` the platform works it out from the agent's tools and what they returned, exactly as before. The built-ins ship with theirs (`static` and `reverser` read code, `triage` and `android_static` are `static`, `judge`, `reporter` and `lead` are `other`). The settings API refuses a new definition without a category, under the field; the console's agent editor shows a required select with a text saying what the category decides, locked on the built-ins, and the setup guide's agent step shows it too. The catalog serves the choices (`agent_category_choices`), and the run's roster carries each agent's `category` beside its `role`.

### Upgrading

- **Stored agent definitions are given the category their role and tools fit (T-559).** Migration `20261103000000` writes it into each stored definition that is not a built-in and names none, from its role, the kinds of its tool references and its input slices, never its name: a `static` role and a `generic` or `lead` definition holding a `provider` reference read code, a `sandbox` reference or sandbox slice is `dynamic`, sandbox network slices alone are `network`, reputation capabilities alone are `intel`, and anything else is `other`, which keeps the steps it had. The log names each definition set to `other` this way, and each entry it could not fit, which is left as it is. A database that has not run it still loads: the settings model reads the same value. Nothing is written for a built-in, whose category comes from its seed.
