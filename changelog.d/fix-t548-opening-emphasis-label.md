### Fixed

- **A technique value ends at a CONFIDENCE or EVIDENCE label written after it with opening emphasis (T-548).** A TECHNIQUE value written on one line with another field ended only at a label with nothing before it, so `TECHNIQUE: T1027 **EVIDENCE**: [ev_0002]` kept the evidence label in the technique line and read no technique id from it, while an evidence value already ended at such a label. A CONFIDENCE or EVIDENCE label after whitespace now ends the technique value with `*` or `_` before it as well (`**EVIDENCE**:`, `*CONFIDENCE:`, `__EVIDENCE :`), in the colon spellings a label at a line start is read in. The labels are read in capitals there, as before, so prose such as "**important** evidence" or "**Evidence**: see above" stays in the value. A long run of spaces or marks before a label is read once. Over 1,000,000 generated texts every read that changes holds this spelling and equals the read of the same text written without the opening emphasis; the stored model texts of the benchmark runs that hold it are flattened copies read as no claim block, so none reads differently.
