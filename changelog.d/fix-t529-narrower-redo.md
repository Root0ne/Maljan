### Fixed

- **A narrower call is no redo of a failed one (T-529).** A failed call counted as redone (T-494 D6) when a later call of the same tool asked the same question with any argument absent or null on either side, or with the value the failure's message named replaced by any other, so a redo that asked less counted: the whole routine asked and three instructions of it answered, or a read of 0x1000 bytes refused and a read of 4 answered. A redo of the same tool is now never narrower than the failed call. An argument the failed call left absent or null and the redo sets counts only where the failure's own message names that argument as a word of its own (the call was refused for it, as a null `timeout`, `limit` or `offset` refused as no valid integer) and the redo's answer is not cut, read as for every answer (the byte budget, the tool-output guardrail, an answer not held whole); a failure that named no such argument ("disassemble X" redone as "disassemble 3 instructions of X") is no redo. A refused value the redo replaces by a number counts only when that number, decimal or `0x` hex, is not smaller than the refused one. A call of another tool that lists the function whole redoes a failed listing as before. Every failed call is still counted and listed as failed; only the redone list is narrower. Known limit: an argument the failed call set and the redo leaves absent or null still counts, as before, though the tool's default for it, which the ledger does not carry, may ask less. Offline, over the stored ledgers of run7, run5, run4, local8, haiku4, haiku5, haiku7 and haiku8: haiku5's 10 redone calls stand, the two decompiles refused for a null `timeout` and the four cross-reference lists refused for a null `limit` and `offset` each redone by the next call that set it, with a whole answer (no reference, or two); 3 of run7's 4 no longer count, decompiles that failed with "Cannot find function" and were redone by a call of the same tool name that set a `timeout` the failure never named; haiku7's 2 and haiku8's 3 stand.
