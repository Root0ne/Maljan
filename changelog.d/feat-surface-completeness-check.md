### Added

- **A checker that proves every finding of a job is on every surface, whole and the same (`python -m scripts.audit.surfaces`).** It reads a job's own decisions (verdict, confidence, severity, family, published techniques, the IOC table with each value's publication, the report sections with their items and citations, key findings, the network values the judge kept, the sandbox's processes, the generated rules) and looks for each one on every surface that should carry it, by a declared finding kind x surface table (`scripts/audit/surface_map.json`, each row naming the code it was read from): the job detail, the report row and full report, the Markdown and HTML, the STIX export and the judge's bundle, `/mitre`, `/iocs` with and without `include=all`, the evidence ledger, events, run summary, usage, follow-ups, the ATT&CK layer, the rule downloads, the job package, and the web console's tabs by a field map read from `apps/web/src` (`scripts/audit/web_fields.json`). It names missing, cut, renamed and orphaned items, citations that resolve to no ledger entry, sections a surface draws blank or in part, and scalars two surfaces disagree on. A surface that filters on purpose is held to its rule (the default `/iocs` is exactly the published `include=all` rows; the Markdown cuts a cell only where its rule cuts it). It reads a stored run directory or a running API (read-only), writes a JSON report and a short summary, and exits 1 on any defect.
