### Fixed

- **A technique value ends at a CONFIDENCE or EVIDENCE label a list, quote or heading mark leads (T-549).** A TECHNIQUE value written on one line with another field ended only at a label with nothing or `*`/`_` before it, so `TECHNIQUE: T1027 - EVIDENCE: [ev_0002]` read the technique line `T1027 -` and no technique id from it, while an evidence value already ended at such a label. The technique value now ends at a label with any mark a line may begin with before it (`- EVIDENCE:`, `1. CONFIDENCE:`, `> EVIDENCE:`, `## CONFIDENCE:`), as the evidence value does, except a number with a closing bracket, which ends a note ("T1027 (step 2) CONFIDENCE:") rather than leading a list. The labels are read in capitals with their colon there, as before, so prose such as "T1027 - see note" or "T1059.001 > 2 EVIDENCE" stays in the value. A long run of spaces and marks before a label is read once. Over 1,000,000 generated texts every read that changes holds this spelling and differs only where the technique value ends, at that label; no stored model text of the benchmark runs reads differently.
