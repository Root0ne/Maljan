### Security

- **An untrusted server's vendor keyword that holds a schema is read as hiding an argument (T-460).** The disclosure reading skipped every unknown keyword starting with `x-`, so an untrusted server could list a path or content argument under, say, `x-args` and have the tool read as sending nothing. A vendor value that looks like a schema is now left unread for an untrusted server, at any depth, and its tool is read as sending the sample whatever its hints: a mapping holding any keyword that holds schemas (`properties`, `items`, `prefixItems`, `anyOf`, `oneOf`, `allOf`, `not`, `additionalProperties`, `patternProperties`, `if` and the rest), a `$ref` or `$dynamicRef`, or a `type` naming a JSON Schema type, and a list or map one of whose values is such a mapping. Other vendor values, a UI hint such as `{"type": "slider"}` among them, stay annotations. A trusted server's vendor keywords, the program reading and the shipped Ghidra, radare2 and VirusTotal readings are unchanged.
