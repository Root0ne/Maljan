### Security

- **An untrusted server's vendor keyword that holds a schema is read as hiding an argument (T-460).** The disclosure reading skipped every unknown keyword starting with `x-`, so an untrusted server could list a path or content argument under, say, `x-args` and have the tool read as sending nothing. A vendor value that looks like a schema is now left unread for an untrusted server, at any depth, and its tool is read as sending the sample whatever its hints. A mapping looks like a schema when it holds a schema keyword in that keyword's own shape: one schema under `items`, `not`, `additionalProperties`, `if` and the like; a list of them under `anyOf`, `oneOf`, `allOf`, `prefixItems` or `items`; a map of them under `properties`, `patternProperties`, `$defs` or `dependentSchemas`; a `$ref` or `$dynamicRef` as text; a parameter's `schema` mapping; or, where it has a name (the vendor keyword's own, its key in a map, or a parameter list member's own `name` or `in`, as in `[{"name": "path", "type": "string"}]`), a `type` naming a JSON Schema type. A list or map holding such a mapping at any depth counts too; one with more nested lists and maps than the walk's cap is read as holding one. Other vendor values stay annotations, at full strength: a UI hint such as `{"type": "slider"}` or `{"widget": "select", "items": ["a", "b"]}`, a list of typed form fields, and a long list of example records. A trusted server's vendor keywords, the program reading and the shipped Ghidra, radare2 and VirusTotal readings are unchanged.
