### Fixed

- **The analyst report prints a drafted rule only where it matches its sample by content, each with a Precision line (T-457, T-473).** The YARA draft matched the published indicators, which a sample that keeps them encoded holds in no byte, so on the stored Latrodectus runs it matched its own sample by its sha256 and import hash only (0 of 5 strings found), and the analyst report printed it anyway. A file rule now prints its body in the analyst report only where its strings clause held on the sample; one that matched by a hash alone, was not run against the sample, or was stored before that check is named in §8.2 with the reason, and the evidence bundle and the single-file report still print every body. Every rule the analyst report prints carries a Precision line saying what it was measured on and that no retro-hunt was run. A value the code passes to an API argument now prints its binding chain in the analyst report's indicator table, which only the draft's comment had carried there.
- **The YARA draft matches the values the sample stores as they are (T-457).** A decoder's seed, which a seed-and-length header stores in front of each encoded string, and each function-name hash a resolver found in the file are read from the ledger by the answer's kind (`reporting.code_constants`, kept in the report's `code_constants`) and drafted as hex strings in a group of their own with its own quantifier, beside the published strings. A value below 0x10000 or of fewer than three distinct bytes, a lone hash hit and an answer about a carved file are not read; one value alone makes no group; past twelve values the draft says how many it left out. A draft with none of them is written as before.
### Added

- **A hunting query in the analyst report's §8.3 (T-457).** Built from the published user agents and URL paths (a path of fewer than three characters besides its slashes is left out), with the published hosts excluded, so a match is a candidate for more of the same infrastructure; printed live in a code block, in neutral field names. A run that drafted no rule prints none, and renders byte for byte as before.
