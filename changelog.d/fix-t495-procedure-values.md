### Fixed

- **An ATT&CK procedure is asked only for the values of its own technique's behaviour (T-495).** The check that a one-sentence procedure keeps what its claim shows compared it with the first sentence of the technique's first claim, and asked for every value in it. That sentence often describes something else (the command runner several discovery techniques share, a Desktop listing before the process listing), so a retry pulled off-topic values into procedures: T1057 led with the Desktop listing, T1105 and T1106 became the same sentence, and section names such as `.text` were asked for. The procedure is now compared with the part of the first claim that names its technique: the sentence or list item naming the technique id (not a remark that names other published techniques too), else the clause naming the most words of the technique's name, else the first sentence as before. Only identifying values are asked for; a section name or extension, an argument name (`arg2`) and a one-byte constant (`0x0e`) are not. A value of the technique's own behaviour that the procedure drops is still asked for. On the stored haiku8 first answer, the check now raises 8 findings instead of 16.
