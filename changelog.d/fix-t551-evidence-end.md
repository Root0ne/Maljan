### Fixed

- **An evidence or technique value keeps the number written before a label on its line (T-551).** A value written on one line with the next field ended at a label led by a number with a full stop or a closing bracket, read as a list mark, so `EVIDENCE: [ev_0014] (seen on port 443) CONFIDENCE: 0.9` stored the evidence `[ev_0014] (seen on port` and `TECHNIQUE: T1071 over port 443. EVIDENCE:` read the technique line `T1071 over port`. After words on a line such a number ends a sentence or a note: of the 142 numbers written before a capitals label after whitespace in the stored benchmark texts, every one does, and none leads a list. Both values now keep it and end at the label after it; a number leads a label as a list mark only at a line's start, and any other mark a line may begin with (`- `, `> `, `#`, `**`) still ends the value at the label it leads. A long run of spaces and marks in an evidence value (` * * *`) is read once rather than once per mark. Over 1,000,000 generated texts every read that changes holds a number before such a label and differs only in that an evidence or technique value the old read cut before it now runs past it; with the stored answers' one-line claims set out with their evidence on a line of its own, 72 claims in 45 texts keep the last number of their evidence and nothing else in their read changes.
