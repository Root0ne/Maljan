### Fixed

- **Every JSON-schema form an MCP tool declares an argument in now builds, and its value reaches the server (T-349, T-352).** A property typed as a list (`"type": ["integer", "null"]`) crashed the tool build with `TypeError: unhashable type: 'list'`, so the whole server was lost, and a property with no `"type"` was annotated as a string, so an object behind a `$ref`, an integer in an `anyOf` and a number in an `enum` were refused before the call was sent. A property that is not a plain type (a type list, `nullable`, `anyOf`/`oneOf`/`allOf`, `enum`, `const`, a nested object, an array with `items`, `additionalProperties`, a `$ref` or no type at all) is now offered the server's own schema with every local `$ref` into `$defs`, `definitions` or any other part of the tool's schema written out in place; a nested reference resolves all the way down and a recursive one stands as the bare type of what it names where it would repeat, so it never loops. Its value is checked for its Python shape and the server checks the rest. An optional integer a server writes as `anyOf: [integer, null]` is offered as an integer, no longer as a string. The server is not trusted to be well-formed: a property whose written-out schema passes 2000 nodes, 32 levels or 64 KB, is not a valid Draft 2020-12 schema (a draft-4 boolean `exclusiveMinimum`, a tuple `items` list, `"required": true`, an empty or repeated type list) or cannot be read is offered as the plain type it was before, with a warning naming the server, the tool and the property, and every other property keeps its schema. A reference that is not `#` or a `#/` pointer (an `#anchor`, a remote URL) is not resolved, a `$ref` that is not a string is left out, a keyword that is not a schema and still holds a `$ref` (`examples`, `const`, an `x-` extension) is left out, and a default that holds a `$ref` is left to the server, so no client that converts the schema meets a reference. A schema nested too deep to read its null rules still builds. Gemini's client, which refuses an enum whose values are not strings and reads `["integer", "null"]` as a string, is bound each such tool with the enum's values named in its description (its type kept or read off the values) and the type list as an `anyOf` of that type and `null`, which it reads as nullable; a `default`, `examples` or `const` value is never rewritten. A tool whose properties are all plain types is offered byte for byte what it was, checked over every tool of the built-in MCP servers and the VirusTotal tools; a `null` for an optional field that does not admit one is still the argument left out.
