### Fixed

- **A field label written on the line of another field is read with a space or closing emphasis before its colon (T-546).** A claim's fields written on one line read a later label only when its colon followed it directly, so `EVIDENCE: [ev_0002] CONFIDENCE : 0.8` folded the confidence into the evidence and counted the claim as one without a confidence, and `TECHNIQUE: T1027 EVIDENCE : [ev_0002]` kept the evidence label in the technique line. A CONFIDENCE, TECHNIQUE or EVIDENCE label after whitespace now ends the value before it and is read as its field in the spellings a label at a line start is read in (T-541): `CONFIDENCE :`, `CONFIDENCE**:`, `**CONFIDENCE** :`. The labels are read in capitals there, as before, so prose such as "the confidence : high" or "evidence : see above" stays in the value; a technique value still ends only at a label written without opening emphasis. A long run of spaces around a label is read once. Over 1,000,000 generated texts every read that changes holds one of these spellings and equals the read of the same text written with a plain colon; no stored model text of the benchmark runs changes.
