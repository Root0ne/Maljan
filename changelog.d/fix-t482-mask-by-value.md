### Security

- **Shown text is masked by every secret value the platform holds, in each encoded form (T-482).** The masking (`maljan.core.settings_masking`) found a credential by where it stands, so a password after a path, beside a UNC share or behind a JSON escape was kept wherever no rule read its place (`C:\x=u:pss@h:8080`, `u:pss@h:8080,x`, `x;u:p\q@h`, `u:/p\x@h`, `\\pss@SSL\x@h:8080`). Now, after those rules, every value the settings hold is masked wherever it appears (`masked_values`): the credential fields (`SecretStr` and the names the catalogue reads as a credential), every tool server's `env` value, a source's own credential, every value of an encrypted settings row, the password and credential query values of every stored address and its `user:password` userinfo whole (`settings_catalog.shown_secret_values`). Each is found as written, URL-encoded (`quote`, `quote_plus`, either case of escape), JSON-escaped once and twice, and base64-encoded (standard and URL-safe, padded or not, at any of the three offsets inside longer base64, so `Basic <user:pw>` is found from the password alone). Overlapping values are masked as one run. A value shorter than eight characters (the event scrub's floor) is masked only by the structural rules. One pass, linear in the text: a trie pattern, and an automaton for a set nested deeper than the regex engine compiles. The values are registered by scope where settings are read in force (an app, a worker, a job, the store read or saved and before the console's read, the console's cached settings on each rebuild), and only counts are logged. Every caller of `masked_text`, `masked_args`, `masked_server`, `redact_url` and the run snapshot gets it without change; the structural rules run first and are unchanged, so nothing masked before is kept now. Where a server's `env` value also stands in another setting (a path, an argument), the console shows it masked, and a save that sends it back as shown keeps the stored value; the efficiency fingerprint's per-server digest of such a server changes, as it is taken over the masked fields.
