### Security

- **The analysis and network servers can run in containers of their own, and the triage pack's own readings of the sample then run there (X2, T-006).** Every reading of the sample the triage pack makes itself — the identity, hash and signature readers, the six format readers, strings and indicators, YARA, capa, FLOSS, the API-hash, string-blob, constant and function-index readings, the UPX header check and unpacker, the directed-text scan of the file and of the unpacked program, the capture summary — and the analyst input's toolchain fingerprint now go through one register of readings (`maljan.tools.readers`), each standing in for the tool of the same function a server declares. Where the server declaring that tool also declares the readers' delivery primitive (`run_reader`, never shown to a model), is switched on and is reached at an address, the reading runs there, on that server's own copy of the sample under its declared `sample_mount`, the job's capture handed over through the artefact store, and the worker reads only the answer, as strict JSON of at most 64 MiB; a reading that raised there is raised again here under its class name, a server that was handed no copy of the sample fails the reading and says so, and a server that declares the tool but not the primitive leaves the reading in process. Each such call waits its reading's own clock (capa's, FLOSS's, YARA's, else what is left of the pack's budget) and half a minute more, and the session of a block that declares the primitive waits as long as a reading may take. Where the server is a child of the worker, as shipped, every reading runs in process exactly as before. The compose file adds `analysis-mcp` and `network-mcp` under their own profiles (`analysis`, `network`): the worker's image and source, read-only, `--http` behind their own token, no capability and no way to gain one, a pids limit, a read-only root with a sized `/tmp` tmpfs for each job's staging (swept 24 hours after it last changed, not when the job ends), the samples read-only at `/data/samples`, an internal network of their own shared only with the API, the worker and a bare relay (`analysis-port` 8098, `network-port` 8099), no platform credential, and a memory-and-swap ceiling (`ANALYSIS_MEM_LIMIT` 8g, `NETWORK_MEM_LIMIT` 2g). A test lists every place the worker's code still opens a file's bytes or hands them to a parser itself, with why: hashing and routing the sample, handing its bytes on unread, the process table, the readings' own code, and the readings left for a later change — the network analyst's capture slice, the report's capa and YARA fallback, the report's check of its YARA draft against the sample, a static provider's anti-analysis image read, and the family-feature hint (off as shipped). Shipped settings, local runs and stored runs replay unchanged.
