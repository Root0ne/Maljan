### Changed

- **On Claude, an agent's later debate rounds read the triage pack from the prompt cache instead of writing it again (T-500).** Each revision's first request wrote its whole prompt (98–228 K tokens in haiku8) and read none of it: the only breakpoint sat on the newest user turn, whose entry lives five minutes, while an agent's rounds start twelve to thirty-two minutes apart. The triage pack at the head of a turn, noted with its length where the platform puts it there, is now sent as its own text block with a breakpoint that lives an hour (`llm.anthropic.pack_cache_ttl`, `1h` by default; `5m`, or `off` for none); the two blocks joined are the turn's text, every other breakpoint keeps `llm.anthropic.prompt_cache_ttl`, the pack's stands first and is never shorter-lived, as the API requires, and no request carries more than four. A turn that begins with a pack once sent this way is sent the same way again, noted or not, so a replayed thinking block stays valid. Replayed over haiku8's 184 stored requests, the run costs 1.18 USD less (15.62 to 14.44 USD simulated, 15.41 billed); a global one-hour lifetime would have added 2.92 USD and stays the operator's choice. Moving the revision prompt's ISR framing after the pack, which would let the first round share the prefix too, waits for the revision-prompt change in flight (T-364). Other providers send what they sent.
- **The mediator's rounds read one cached head: the triage pack and the sample's identity come first, the run state after them (T-500).** The run state, regenerated every round, led the mediation's turn, so the five mediations of haiku8 shared about 920 characters and every round wrote its prompt again. The pack and the identity now lead, noted as standing facts, so the pack's own breakpoint is written in the first round and read in each later one; the run state, the reports and the history follow, word for word as before. Replayed over haiku8, the mediator's spend falls from 0.77 to 0.65 USD. The verdict, the technique question and the analysts' turns keep their order. Opening the mediator's tool loop only when a line names something to read is not done: an agent's tool use is never restricted.
- **On a Claude model that thinks by default, the report's structured calls are asked for their JSON in text, with no schema tool beside `read_evidence` (T-500, T-497 D12).** No tool choice is sent for a schema, and such a model wrote the JSON as text in every one of haiku8's 22 structured calls (19 composer sections, the narrative and the judge's technique question), each logged as an answer that "carries no object the schema reads". The provider now says which models answer so, and that it asks for no JSON-schema answer natively: the pinned langchain-anthropic's `json_schema` method replaces a model's bound tools and cannot read a reply that reads. Those calls take the text path from their first request, said once per model; the answer is read by the same parser as before, so nothing that was parsed is lost. A schema offered alone (the mediation's extraction), older Claude models and other providers keep the tool.
