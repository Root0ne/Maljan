### Changed

- **The analysis page is one sticky header and six tabs (T-464).** `/analysis/<job id>` now opens on the layout the preview showed: the header carries the verdict, the verdict's confidence as a ring, the family and up to five classification chips, file type and size, the SHA-256 with copy and the other hashes on demand, status, duration and when it was analysed, one Export menu and Ask; plain-language remarks under it appear only when the run is degraded, unfinished, stopped, failed, its verdict was inferred, or its verdict and severity disagree. The six tabs are each their own URL with a count badge: Overview, Behaviour, Network, Static & code, Indicators & detection and Evidence. Every finished run shows all six; a block with nothing in it keeps its place and says "Not found". While a job runs only Overview, which shows the stages and links to the live discussion, and Evidence are offered; the live discussion keeps the stages strip above it. Overview is the summary and all key findings (eight, then "show more"), the stored narrative paragraphs or the reason no summary was written, a row of counts, the answers to the questions asked at submission, the findings table, the extracted configuration, every recommendation with its category and technique, and the follow-up questions asked so far. The other tabs hold today's content unchanged: Behaviour is the technical analysis, the sandbox behaviour, ATT&CK and persistence; Network leads with domain, IP, URL and suspicious counts and holds the enrichment button; Static & code is the file identity (with its reputation) and the static analysis; Indicators & detection is the rule matches, generated rules, indicators, the STIX bundle and attribution; Evidence is the records, the analysts' discussion with the agents table, one view per operator agent or tool server (never a top-level tab), the sections no tab draws, and a collapsed "Run quality" section holding the stages strip, the profile, the verdict and severity line, the degraded-run reasons, QA warnings, evidence counts, time per stage, what the report's checks left standing and the run record. Every old route (`/conversation`, `/identity`, `/dynamic`, `/persistence`, `/capabilities`, `/attribution`, `/detection`, `/defense`, `/agent/<key>`, `/server/<key>`, the older `/live`, `/ttps`, `/rules` and the rest, and `/preview/analysis/...`) redirects permanently to the tab that holds its content, at the block it became. Every download is in the Export menu under the file name it always had (`maljan-<hash>-mitre.json`, `maljan-stix-bundle.json` or `-draft.json`, `maljan-attack-layer.json`, `maljan-<kind>.yar`, …), the STIX item falls back to the bundle stored with the report when the endpoint fails, and the detection block no longer repeats the STIX, Navigator layer and per-kind rule downloads; a rule keeps its own copy and download and the graph its SVG and PNG. Internal words stay on Evidence: "ledger" reads "evidence", evidence ids outside Evidence are small superscript marks that open the evidence drawer, the reputation tooltip reads as fields rather than a dumped object, and "judge", "producer", "report model" and "RAG candidates" read in plain words. Light and dark themes apply to every tab of the analysis page. The `NEXT_PUBLIC_UI_NEXT` flag is gone. Console only; no report, API or stored run changes.
