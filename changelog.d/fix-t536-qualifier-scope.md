### Fixed

- **A ledger fact qualifies a section 5 sentence only on what that sentence names (T-536).** The agreement round accepted a fact's clause on a section 5 sentence wherever the sentence's whole section named the fact's address, value or call, so "The sandbox recorded six dropped items: … files/0x00020000000003ba-104.dat" could gain "a later call for offset 0x6f48 answered it, so the address was not left unread", because a paragraph two on named the download routine 0x6f48 (haiku8). A fact now grounds a sentence that names its routine, address, value or call. A fact about a routine (one whose code no entry lists, or one an entry lists) or a bound value also grounds a sentence that states an absence ("No environment check is established.", "The mutex name is not established.") wherever its section names what the fact is about; a failed call answered later never does. Over the eight stored runs (run7, run5, run4, local8, haiku4, haiku5, haiku7, haiku8) the sentence and fact pairs the platform would accept fall from 11,744 to 3,859: 592 where the sentence names the fact and 3,267 where it states an absence. Every pair accepted now was accepted before. The prompt and the `agreement.rewrite_ungrounded` finding state the rule.
- **An address counts only as a word of its own in the agreement round (T-536).** A hex run inside a path, a file name, a URL, a registry key or a longer identifier no longer names an address a fact is about. A word names an address when it is one (`0x6f48`, `FUN_00406f48`, `6f48h`, bare hex, a decompiler's name written with `0x` such as `fcn.0x33ac`), or a range or pair of them (`0x10-0x40`, `0x10..0x40`, `0x7504/0xd1c8`); spaces, brackets, quotes, list and clause marks, operators, `~`, `#`, `%` and arrows end a word, a trailing ellipsis is no part of it, and a slash with nothing on its other side (`0x401000/`, `/0x5a10`) joins no path segment. The facts shown, the routines a passage calls unread and the grounding of a rewrite read addresses this way. No pair changes on the stored runs.
