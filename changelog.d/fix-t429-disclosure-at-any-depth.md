### Security

- **A path or the file's content is read as sending the sample wherever a tool's schema puts it (T-429).** The disclosure reading walked an argument's schema only two objects deep, followed only `properties`, `anyOf`/`oneOf`/`allOf`, a single `items` and `#/...` references, and read a reference it could not follow as nothing, so a bytes or path argument a server nested further down, or behind another keyword, was not read as sending the sample. It now walks every keyword that holds a schema at any depth: `items` (one or a list), `prefixItems`, `additionalItems`, `contains`, `unevaluatedItems`, `if`/`then`/`else`, `dependentSchemas` and the schemas of `dependencies` as the argument's own schemas; `additionalProperties`, `unevaluatedProperties` and `patternProperties` as arguments, named by a pattern that is an anchored literal (`^path$`) and otherwise with no name of their own, so they are read as sending unless their type (number, integer, boolean, null) holds no path and no bytes; a free-form map (`additionalProperties` or `unevaluatedProperties` of `true` or `{}`) is read by the object's own name, deliberately looser than a map typed `{"type": "string"}`, which is read as sending: a `dict[str, Any]` argument is listed exactly so, and four of the platform's own tools take one; a pattern that is no anchored literal never is (`not` is not read). An argument named only by `required`, by the lists of `dependentRequired` or `dependencies`, or by the `const` or `enum` of `propertyNames` is read by that name, of any value. A `true` schema is read as any value, so its argument's name is still read, a `false` one as none, and any other value where a schema belongs is read as sending, as is a mapping or a flag under a keyword the walk does not know (annotations, value-range flags, `$defs`/`definitions`, `not` and vendor `x-` keywords excepted). Local references are followed however they are written (`#`, a JSON pointer, percent-escaped or with `~0`/`~1`, a list index, an `$anchor`), each looked up once, with a reference's sibling keywords read beside its target; each chain of references has its own budget. Each schema is read once for each argument it belongs to and each object's own arguments once, so the walk grows with the schema's size, within the existing caps (512 schemas read, as many waiting, 32 references per chain) and cycle guard. The reading fails closed: where the walk stops at a cap with anything unread that could take a path or the file's content, or any reference cannot be followed (not local, naming nothing, a `$dynamicRef`, an anchor defined twice or inside an embedded resource, or a reference inside an embedded resource, which resolves against that resource's own `$id`), the tool is read as sending (`discloses_sample`; a program-analysis tool as sending its bytes), whatever its hints. Argument names are read NFKC-normalised, and an untrusted server's argument whose name keeps any character outside ASCII, or a control, format or combining character, is read as sending. The shipped Ghidra, radare2 and VirusTotal listings and the MCP schema corpus (294 tools) read exactly as before.
