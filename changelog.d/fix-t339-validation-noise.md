### Fixed

- **Fewer validation questions that a true claim could not answer, and one more contradiction the report is asked about (T-339).** The does-not-describe question read a "was not observed" sentence as a negation of every sentence of the claim, so a static claim that names its technique's call in one sentence and adds "This is a code path only and was not observed." in the next was asked whether it describes its technique; the not-seen reading now reaches only the sentence it stands in. An acronym's plural ("APIs") now shares a term with a catalogue name that writes the acronym ("Dynamic API Resolution"). A TECHNIQUE line with a closing note in brackets is read by an allow-list: a note whose every content word is the id's own vendored word (its catalogue name, card or API rule) or a reference or layout word ("T1071.001 (configured channel)", "(one per command, as listed)") leaves the id read; a note that says the id is not asserted, followed only by where or by what ("T1547.001 (not supported by the traced code)", "none (T1055 withdrawn)"), claims none, as the unread line did; any other note keeps the line asked about, as before. Ids separated by semicolons are a list, a dash before a bracketed note claims none as "none" does, and the one-word technique name "At" no longer turns "none asserted at this level" into a question. The absence question no longer reads a sibling's word as a sub-technique's absence ("not packed" under Dynamic API Resolution), nor a child's word as a parent's absence when the claim also names the family's behaviour without negating it ("strings XOR-encoded; not packed" under Obfuscated Files or Information); "The DLL is not packed." is still asked under the parent. The rule is built from the catalogue's names. A report sentence that says the decompile of a routine "was not obtained", that a cited entry does "not verify" a value, or that "no X is in the evidence" is checked against the ledger as "not read", "not confirmed" and "not in the evidence" already were; a subject that names no address, entry or value ("the sleep timing", "payload-level encryption") is still not judged.
