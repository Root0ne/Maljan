### Added

- **A preview of the redesigned analysis page, behind `NEXT_PUBLIC_UI_NEXT` (T-463).** With the flag set to `true`, `/preview/analysis/<job id>` opens the new layout beside today's pages, which are unchanged: a compact sticky header (verdict strip, the verdict's confidence as a ring, family and up to five classification chips with "+N", file type and size, SHA-256 with copy and the other hashes on demand, status and duration), one "Export" menu grouped Quick / Deep / Data over the existing downloads, an "Ask" panel for follow-up questions, plain-language remarks only when the run is degraded or unfinished, and six tabs that are each their own URL (Overview, Behaviour, Network, Static & code, Indicators & detection, Evidence). There is no score: the report holds none, so the header shows the confidence as stored. Overview is built from the stored report: the summary and key findings, a row of counts that says "Not found" for none and "Not measured" for a count the report does not hold, the findings table with one n/5 severity scale, how each finding is known in the report's own terms (observed running, read from the code, a capability, not observed, or "Not stated" where the report gives no basis), and a caret that opens the evidence behind a row in a side panel, the extracted configuration with copy per value and copy all, and the prioritised recommendations. The other five tabs list what they will hold and link to where today's console shows it. Light and dark themes come from the same tokens, applied before the first paint; the light set applies only to a page that asks for it. Evidence ids the report's prose cites inline become one small link to the evidence panel and are never printed; on a phone the header folds to one row once the page scrolls; while the analysis loads the header shows a placeholder rather than an empty result. Off (404) when the flag is unset.
- **A shared UI kit for the console (`apps/web/src/components/ui`).** Button (primary / secondary / ghost, at most one primary per view), Section (title, count, collapsible, a "Not found" empty state that keeps its place), Tabs (one URL per tab, count badges), severity and verdict pills, KPI tile, a right-side Drawer (focus trapped inside, the page behind it inert, focus returned to its opener), and ExportMenu (menu-button keyboard pattern; an unavailable item stays reachable with its reason), each with unit tests, the Drawer and the menu also in a DOM (jsdom, added as a dev dependency).
