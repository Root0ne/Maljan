### Changed

- **The public name is Malspark, and the docs are published at https://malspark.com/docs/.** The code keeps the name `maljan` (the Python package, the `maljan` command, the environment variables and the repository). The website, with a home page at https://malspark.com, is built and published separately on Cloudflare Pages from this repository's docs: the pages stay in `apps/docs/content/docs`, their images in `apps/docs/public/assets`, and the files served under `/examples/` in `docs/examples`. Pages link to each other under `/docs/`, and the validation-code register writes its links the same way. The README, `CONTRIBUTING.md`, `SECURITY.md` and the issue template point at the new address.
- **The docs workflow checks the content instead of building a site.** The Next.js site app leaves this repository; `apps/docs` keeps a small Node package whose `npm run check` compiles every page as MDX, parses every `meta.json`, and fails on a link to `/docs/...`, `/assets/...` or `/examples/...`, anchor included, that leads nowhere. It runs on every pull request that touches `apps/docs` or `docs`. The npm audit step for the docs site is gone with it, since the check ships nothing.
- **The old GitHub Pages address redirects.** On `main` the docs workflow publishes a two-file redirect site to GitHub Pages: https://root0ne.github.io/Maljan/ leads to https://malspark.com/docs/, any other page to the same page under `/docs/` with its anchor, and `/examples/...` to https://malspark.com/examples/.... The pages are marked noindex and name the new docs home as canonical.
