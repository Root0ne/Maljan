### Changed

- **The public name is Malspark, and the docs are published at https://malspark.com/docs/.** The code keeps the name `malspark` (the Python package, the `malspark` command, the environment variables and the repository). The website, with a home page at https://malspark.com, is built and published separately on Cloudflare Pages from this repository's docs: the pages stay in `apps/docs/content/docs`, their images in `apps/docs/public/assets`, and the files served under `/examples/` in `docs/examples`. Pages link to each other under `/docs/`, and the validation-code register writes its links the same way. The README, `CONTRIBUTING.md`, `SECURITY.md` and the issue template point at the new address.
- **The docs workflow checks the content instead of building a site.** The Next.js site app leaves this repository; `apps/docs` keeps a small Node package whose `npm run check` compiles every page as MDX, checks its frontmatter and that every component it uses is imported or provided by the site, parses every `meta.json`, and fails on a link to `/docs/...`, `/assets/...` or `/examples/...`, anchor included, that leads nowhere, on a relative link or one to the old address, and on an address the old site served that no longer leads to a page. It runs on every pull request that touches `apps/docs` or `docs`. The npm audit step for the docs site is gone with it, since the check ships nothing.
- **The old GitHub Pages address redirects.** On `main` the docs workflow publishes a two-file redirect site to GitHub Pages: https://root0ne.github.io/Malspark/ leads to https://malspark.com/docs/, any other page to the same page under `/docs/` with its query and anchor (a page that moved, such as `/paper/`, to the page that holds its text now), and `/examples/...` and `/assets/...` to the same path on https://malspark.com. The pages are marked noindex and name the new docs home as canonical.
