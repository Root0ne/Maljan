### Fixed

- **A stdio tool server's relative command runs the project's file, whatever directory the backend was started in (T-461).** A block with no working directory of its own had its arguments rooted at the project but its command started as written, so `bin/server` ran from the API's or the worker's own directory, and a console trust grant could hold for a different file than the one a worker started. The command is now rooted by the rule the arguments follow (a relative path into the project is rooted there), and the launch and the trust grant read that one rooted command. A bare program name such as `npx` or `uvx`, an absolute path, and a relative command beside a block's working directory (run from that directory) are started as before, and a grant recorded for any of them still holds.
