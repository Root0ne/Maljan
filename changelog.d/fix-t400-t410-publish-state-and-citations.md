### Fixed

- **A value written with a publish state the IOC table agrees with is not marked again (T-400).** The prose check read only `no: <reason>` as a stated state, so a sentence writing "(publish state: <the table's reason>)" was flagged and the report printed "[not published by this run: …]" right after the state it already gave. A state is now read as stated when it says what the table says: `no: <reason>`; or, in the bracket or clause right after the value, a state under its own name (`publish state: …`, `publication state is …`) that reads as not published (no, not, never, unpublished, withheld, kept out, excluded; no other "publish" in it and no negation just before a withholding word) or restates most of the table's reason with every negation it carries, "not published by this run", or the table's whole reason restated, its words in order and close together. Anything else is asked about as before: a named state that is unknown, pending or "kept as an indicator", one that calls the value published, a reason turned around by a negation it does not carry, and any sentence that claims, unnegated, that the value is published or kept as an indicator. The renderer reads a stored mark's sentence again and prints no mark beside a sentence whose every value carries such a state.
- **A wrong citation kept after its question is marked where it stands (T-410).** A value cited to an entry that does not hold it, kept by the model after the one retry, was recorded as a finding but printed unmarked in the body. It is now marked after its sentence, or beside the evidence of the table row that states it (configuration, identifiers, commands, flags, channels, encryption), with the values as written, the ids cited and the entry that holds the value; a value several entries hold is marked with how many hold it and attributed to none, and several wrong citations of one sentence or row are one mark. The model's ids are printed as written, never removed or replaced. A rewrite that keeps the same wrong citation counts as asked; a wrong citation first written in the retry's answer, in a section or in the summary, is marked as not asked.
